# Python style

Use Python without type annotations in new or edited code and in proposed
snippets. Write `def example(name):`, not `def example(name: str) -> str:`.
Do not add parameter, return, or variable type annotations unless the user
explicitly requests them. This preference does not authorize unsolicited
rewrites of existing code or modification of user-owned files.

# Do not modify

All files belongs exclusively to the user. Do not edit, overwrite,
delete, rename, move, format, or otherwise modify them, including through scripts,
generators, cleanup commands, or Git operations. Do not run it without explicit
user authorization. Requests to help with OpenLane or explain code do not grant
permission to modify these files. Provide explanations or proposed snippets in
chat instead. This restriction persists unless the user explicitly revokes it.
